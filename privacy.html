隐私政策

版本 2026-10-18-v1.1 · VIRGO-01 v1.1.0 · 运营者审核草案 / Operator-review draft

请先了解：消息和文件在网络传输中加密，但服务器会保存和处理聊天内容。获授权的管理员可以为管理、排障或处理举报而查阅记录，查阅需要权限验证并留审计。本服务不提供端到端加密。

1. 独立账号与保存的信息

VIRGO-01 与 MARS 独立运行，不导入或共用账号、数据库或文件。服务保存注册账号、昵称、密码的加盐哈希、头像与简介、好友关系、群组、消息、附件、表情收藏、设置、已读状态、登录设备与会话。为安全和故障定位，还会处理请求时间、网络地址和错误信息。不会向其他用户显示密码或登录 Token。

2. 谁可以访问内容

正常情况下，聊天内容仅供会话参与者、VIRGO-01 服务器及明确获授权的管理员访问。附件、历史消息和搜索均由服务端检查权限。退出群组或被移出后不能继续从服务器读取该群的数据，但无法收回对方此前保存的副本、截图或下载。管理员账号与普通账号分离，查阅聊天与文件需要填写理由并记录审计。能控制此电脑系统账户或磁盘的人仍可能接触本地数据。

3. 加密与基础设施

正式 Web/PWA 与 Windows 客户端的公网连接使用 HTTPS，实时消息使用 WSS，文件通过 HTTPS 传输。语音通话采用浏览器标准 WebRTC DTLS-SRTP 加密；本版本不录制通话。GitHub Pages 提供公开网页；Cloudflare 等配置的反向代理或隧道服务提供网络入口并终止 TLS，可以处理转发内容、连接地址、时间和流量等信息。STUN/TURN 服务用于通话连通性，参与者及基础设施可能获知网络地址。传输加密不等于服务器无法读取内容。

同一电脑上的后台进程可通过仅绑定回环地址的本地连接通信；这些连接不开放给局域网。数据库与文件依靠独立目录、操作系统权限及访问控制保护，本版本不宣称数据库已逐条加密或能抵抗已控制操作系统的攻击者。

4. 多端同步与设备

服务同步消息、已读状态、好友与群聊、个人资料及支持的设置。每个登录设备使用独立会话，可以在设置撤销；撤销后服务端拒绝该会话访问。未选择“在此设备保持登录”时，网页访问凭据只保存在当前标签页。选择后，设备会在 IndexedDB 中用不可导出的浏览器密钥加密保存可撤销的刷新凭据，最长有效 30 天；不保存密码。这不能抵御已控制本站脚本或操作系统的人。退出会清理本设备凭据。公开页面资源可离线缓存，私聊、附件和 Token 不写入 Service Worker 公共缓存。浏览器或系统自身可能保留下载文件。

设备由随机安装标识识别，不根据 IP 或浏览器名称合并。服务器保存每次登录的时间与连接 IP，登录历史最多保留 90 天且每设备最多 500 条，累计次数可以继续保留。普通设备列表不返回完整 IP；获授权管理员查询连接 IP 须填写理由并留下审计。在线状态以服务器连接为准，向好友显示时遵循隐私设置；超过 48 小时显示“不在线”。授权管理员仍可查看实际最近活动时间。

5. 保存、导出与删除

你可在设置导出个人数据或申请删除账号。删除会撤销登录、匿名化个人资料、清除个人设置和关系，并撤回本人消息及符合条件的本人文件。已被其他人消息或表情收藏引用的文件可能继续保存，以免破坏他人内容；他人已经保存的副本也不会被远程删除。普通的“仅为我删除”仅隐藏当前用户视图。

备份可能暂时包含删除前的数据；默认在 365 天后自动清理，管理员可以调整备份保留期限。应用内恢复备份会保留当前账号删除记录并重新执行删除，避免旧备份重新启用已删除账号。管理员导出到其他位置的副本仍需单独清理。普通聊天不因备份保留期限而自动删除；安全审计和必要的系统记录由运营者管理保留。请联系向你提供本站地址的运营者了解实际保留设置或处理历史副本。

6. 本地存储与通知

网页保存连接地址、界面偏好和本标签页的必要会话状态，不放置广告追踪 Cookie。通知和麦克风由系统询问授权，可在系统设置撤销。后台或息屏通知的能力取决于浏览器、设备与网络，本版本不保证所有设备持续收到离线通知。应用不会自行读取你的其他电脑文件。

7. 大致地区与推送

IP 地区默认不向他人展示，开启后仅显示国家和省州。服务器使用本地 IP Geolocation by DB-IP Lite 数据库查询，不把用户 IP 发给外部定位 API。结果可能因 VPN、代理或数据库误差而不准确，不能代表真实居住地；无法确定时显示“未知”。数据库由运营者定期更新。

开启系统推送后，服务器保存该设备的推送地址与加密公钥，使用标准 Web Push 加密传递通知。Apple、Google、Mozilla 等浏览器推送基础设施会处理连接和投递元数据。默认隐藏消息正文；用户可以选择只显示发送者或显示正文，锁屏上可能被他人看到。支持免打扰、按会话静音及设备开关。退出账号、撤销会话或失效订阅会停止对应后续投递；系统已展示的通知会尽力清理。

iPhone 需要支持 Web Push 的系统并将网站添加到主屏幕。系统权限、免打扰、省电和网络均可能影响通知。测试按钮会区分推送服务接收、系统显示回执和无法确认；服务接收不保证锁屏响铃。Windows 桌面客户端的原生提醒要求程序仍在运行。

8. 联系与更新

联系邀请你使用 VIRGO-01 的本站运营者处理数据、权限和投诉问题。注册会记录你同意的政策与条款版本及时间。本草案仅描述本版本实现，应由运营者在实际运营环境中审核；重大变更应重新告知用户。

English version

Privacy notice · version 2026-10-18-v1.1

VIRGO-01 is independent of MARS. We store account/profile data, salted password hashes, relationships, messages, attachments, stickers, settings, receipts, device sessions, and security/operational metadata. No passwords or session tokens are exposed to other users.

Traffic is encrypted in transit, but this is not an end-to-end encrypted service. The server processes and stores content. Explicitly authorized administrators may inspect saved conversations and files for administration, troubleshooting or abuse handling, with permission checks, a reason and an audit entry. Only current authorized participants receive content through ordinary APIs. Previously downloaded copies cannot be revoked.

Public Web/PWA/Windows connections use HTTPS/WSS; voice uses standard WebRTC DTLS-SRTP and is not recorded. GitHub Pages hosts the public shell. Configured TLS proxies/tunnels (such as Cloudflare) terminate TLS and can process forwarded content and connection metadata. STUN/TURN infrastructure and call peers may learn network addresses. Local backend communication is loopback-only. Storage is protected by independent directories and OS/application access controls, not a claim of encrypted-at-rest message storage or protection from a compromised OS account.

Devices have separate revocable sessions. Supported account data and read state synchronize across devices. Without keep-login, credentials stay in tab session storage. Opt-in keep-login encrypts a revocable refresh credential (up to 30 days) in IndexedDB using a non-exportable browser key, never a password; same-origin script or OS compromise remains outside that protection. A random installation ID groups devices. Raw-IP login history lasts up to 90 days/500 entries per device and requires reasoned administrator audit to view. Presence respects sharing preferences and shows offline after 48 hours. Local DB-IP Lite provides opt-in coarse country/region estimates, not residence and not precise location, without external per-IP queries. Standard encrypted Web Push uses browser push providers, stores subscription endpoints/keys on the server, hides message text by default, and cleans invalid/revoked subscriptions. iPhone needs a supported installed PWA; OS restrictions can prevent display or sound even after provider acceptance. Native Windows alerts require the app running; public shell caching excludes private API data, media and tokens. Notifications/microphone require system permission. Background notifications depend on browser/device support.

Account export and deletion are available in settings. Deletion revokes sessions, anonymizes profile, clears personal settings/relationships, withdraws your messages and removes eligible owned files. Files referenced by others' messages or saved stickers can remain. Backups can temporarily retain earlier data and expire after 365 days by default, configurable by the administrator. In-app restore preserves the current erasure ledger and reapplies account deletion; independently exported backup copies require separate operator cleanup. Ordinary chat is not automatically expired by the backup retention setting. Security audits are retained by the operator. Contact the person who invited you for retention, access or deletion questions. This is a draft for operator review, not a guarantee of legal compliance.
